# 论文大纲

## 题目：基于 LangGraph 的智能财务顾问系统设计与实现

**Design and Implementation of an Intelligent Financial Advisor System Based on LangGraph**

---

## 摘要

> 随着大语言模型技术的快速发展，AI Agent 正在从文本对话走向工具调用与自主决策。然而，将 LLM Agent 应用于财务顾问领域仍面临三个核心挑战：如何编排复杂的 Agent 工作流、如何管理跨会话的用户上下文、如何保障 Agent 工具调用的安全性。本文设计并实现了一个基于 LangGraph 的智能财务顾问系统，提出了包含 12 节点的 StateGraph 编排方案、四层记忆系统、Redis Checkpoint 持久化与优雅降级机制、以及三级安全防线。系统已通过 609 个单元测试和 22 个 Agent 评估用例验证，完成从 0% 到 100% 的灰度发布，并在阿里云 ECS 生产环境稳定运行。

**关键词**：LangGraph；智能财务顾问；大语言模型；Agent 编排；记忆系统；安全防线
