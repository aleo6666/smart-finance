## 四个题目，选一个

### 🥇 A：Agent 架构主线

> **基于 LangGraph 多智能体的智能财务管理平台设计与实现**

- **覆盖**：12 节点编排 + 四层记忆 + Checkpoint 持久化 + 三级安全 + 灰度 100%
- **适合**：主流 CS 导师，话题有热度，答辩有话说
- **风险**：无，最稳

---

### 🥈 B：持久化 + 容错线（差异化最大）

> **支持状态持久化与优雅降级的 LangGraph 多智能体财务系统**

- **覆盖**：以 Checkpoint 持久化 + 探针检测 + 三级降级为核心卖点
- **适合**：系统架构 / 分布式方向导师，答辩时有硬核技术细节可讲
- **风险**：题目稍长，部分导师可能觉得"不就是存个状态"——需要答辩时讲清楚为什么这是真问题

---

### 🥉 C：安全防线线

> **面向大模型智能体的安全财务管理系统设计与实现**

- **覆盖**：SQL AST 守卫 + 可信注入 + interrupt 确认 + Checkpoint 探针
- **适合**：信息安全方向导师
- **风险**：安全占论文比重可能不够（实际只占 1.5 章），需要把持久化也归入"基础设施安全"来凑篇幅

---

### ④ D：企业工程线

> **基于 AI Agent 的企业级 SaaS 财务管理平台设计与实现**

- **覆盖**：多租户 + RBAC + 审计 + CI/CD + MIT 开源 + 100% 上线
- **适合**：偏工程/偏管理的导师
- **风险**：LangGraph 技术细节被稀释，简历上不如 A 方案亮眼

---

## 推荐：🥇 A

不解释。找导师时如果导师有明确偏好（安全/架构/工程），再切 B/C/D。
