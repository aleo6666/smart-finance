# 复杂记账测试集（Multi-Record Eval Set）

## 是什么

量化"一句话多意图记账"（复杂记账）能力的测试集：用户输入含多个记账意图的句子（"奶茶20和地铁5块"），系统拆分为多笔独立账单的**行为质量**。

**性质**：拆单引擎是**确定性规则**（`nlu.js: buildMultiRecordResult`，LLM 不参与拆单）——测试集锁定的是规则行为在真实场景题目下的正确性，结果 100% 可复现。与 FinAgent 的 LLM 测试集（量化模型输出）互补：这里量化的是"确定性保障"（不误拆/不猜测），那里量化的是"LLM 质量"（意图/字段准确率）。

## 题目分布（30 题）

| 分类 | 数量 | 考察点 |
|------|------|--------|
| 正确拆分 | 10 | 多意图句子 → N 笔，金额/分类/收支逐笔正确 |
| 不误拆 | 6 | "和牛套餐88"式词首"和"、量词"5人"、无金额——**防误拆防御** |
| 缺金额追问 | 4 | 子句缺金额 → 不猜不拆（转追问由上层处理） |
| 收支混合 | 4 | 工资+消费同句 → 逐笔 income/expense 正确 |
| 金额/格式边界 | 4 | 小数、大额、顿号、逗号 |
| 非记账 | 2 | 无金额/分析意图 → 不进拆单 |

## 跑法
