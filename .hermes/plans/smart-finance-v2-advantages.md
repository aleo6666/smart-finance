# Smart Finance V2 — 集百家之长 + 独创优势

> 基于 2026 年记账 App 市场全景分析，制定差异化升级路线

---

## Phase 1: 吸收竞品优点 (拿来就用)

### 1.1 交互速度 — 对标「鲨鱼记账」3秒记账
- [ ] 首页常驻快捷记账入口：语音 + 金额输入框
- [ ] 预设常用分类图标（餐饮🍜/交通🚗/购物🛒），一键选
- [ ] 输入即保存，无需多步确认
- **当前差距:** 需要完整对话轮次 → **目标:** 单次交互完成

### 1.2 银行账单导入 — 对标「随手记」237家银行同步
- [ ] CSV/Excel 账单自动解析（支付宝/微信/银行卡导出）
- [ ] 商户名称归一化（"支付宝-美团外卖" → 美团外卖；"APPLE.COM/BILL" → Apple）
- [ ] 批量导入 + AI 自动分类
- **当前状态:** 已有 `importService` 基础 → **需增强**

### 1.3 语音记账 + 票据扫描 — 对标「薄荷记账」
- [ ] 语音输入 → ASR 转文字 → NLU 记账
- [ ] 拍照小票 → OCR → 自动拆分商品 + 分类
- **当前状态:** 已有 `ocrTool` 和 `visionRouter` → **需增强语音**

### 1.4 数据可视化升级 — 对标「Copilot Money」
- [ ] 消费趋势折线图 / 分类占比环形图 / 月度热力图
- [ ] 净资产变化曲线 / 预算消耗进度条
- **当前状态:** 已有 `echarts` 依赖 → **需优化图表设计**

### 1.5 预算智能预警 — 对标「一木记账」
- [ ] 消费斜率预测：「按当前速度，餐饮类 3 天后超预算」
- [ ] 每日/周/月三级预算提醒
- **当前状态:** 已有 `goalsService` → **需加预测引擎**

### 1.6 多账本 + 家庭共享 — 对标「挖财」
- [ ] 多账本切换（个人/家庭/旅行/生意）
- [ ] 家庭成员邀请 + 权限控制
- **当前状态:** 已有 `ledgers` 路由 → **需加成员系统**

### 1.7 订阅检测 — 对标「Rocket Money」
- [ ] 自动识别周期性扣费（每月同商户同金额）
- [ ] 闲置订阅提醒 + 涨价预警
- **当前状态:** 无 → **全新功能**

## Phase 2: Smart Finance 独创优势

### 2.1 🧠 LangGraph 财务规划 Agent
```
用户目标"3个月存2万" 
  → Orchestrator 拆解子目标
  → Planner 生成月度预算方案  
  → Monitor 每日跟踪执行
  → Advisor 偏离时主动建议调整
```
**为什么独有:** 竞品的"预算"是死的数字上限，Smart Finance 是**动态规划+持续监控+主动干预**的 Agent 闭环。

### 2.2 🎯 财务健康评分引擎
多维指标综合打分（0-100）：
- 储蓄率、负债率、应急资金覆盖率
- 消费结构合理性（恩格尔系数适配版）
- 月度波动稳定性
- 目标达成率

**输出:** 「你的财务健康评分 72/100，主要拖分项：外卖占比过高(38%)、无应急储蓄」

### 2.3 🔮 现金流预测
基于历史 3-6 个月数据 + 固定收支模式：
- 预测未来 30 天每日余额变化
- 预警潜在「资金缺口日」
- 模拟「如果我减少外卖到每周 2 次，年底能多存多少？」

### 2.4 📊 匿名社区基准
- 同类用户（相似收入/城市/年龄）消费结构对比
- 「你的餐饮支出低于深圳同龄人平均水平 15%」
- 数据完全匿名，仅对比不泄露

### 2.5 🎮 记账游戏化
- 连续记账天数徽章
- 月度省钱挑战（"本月目标：比上月少花 500"）
- 消费冷静期提醒（"这件商品在你的心愿单里 7 天了，确定要买吗？"）

### 2.6 🔗 飞书/微信集成
- 飞书机器人：「在群里 @机器人 午餐 35 元」→ 自动记账
- 微信服务号：推送每日/周消费摘要
- **当前状态:** 飞书已连接 → **需开发 bot 能力**

## Phase 3: 技术护城河

### 3.1 Agent 自我进化
```
用户修正分类 → badCaseCollector 记录
              → 自动分析错误模式
              → 更新分类 Prompt/规则
              → 准确率持续提升
```

### 3.2 RAG + 知识图谱
- 将用户历史记录构建为个人财务知识图谱
- 「去年这个时候你在餐饮上花了多少？」→ 秒级语义检索
- 全局模式：「在所有用户中，双十一前后消费增长平均是多少？」

### 3.3 多模态输入
- 文字 + 语音 + 图片 + 截图 四通道输入
- 截图自动识别（支付宝/微信支付页面 OCR）
- **不再需要手动打字**

## 优先级建议

| 优先级 | 功能 | 理由 |
|--------|------|------|
| P0 | 快捷记账入口 | 降低使用门槛，留住用户 |
| P0 | 财务健康评分 | 核心差异化，竞品全无 |
| P0 | 语音记账 | 薄荷记账已验证需求强烈 |
| P1 | 预算智能预警 | 已有基础（goalsService），增量小收益大 |
| P1 | 数据可视化升级 | 已有 echarts，改 UI 即可 |
| P1 | 银行账单导入 | 已有 importService，补齐识别能力 |
| P2 | LangGraph 财务规划 Agent | 技术壁垒最高，但需要前几项先跑通 |
| P2 | 订阅检测 | 新功能，独立模块 |
| P2 | 现金流预测 | 依赖足够的用户历史数据 |
| P3 | 多账本/家庭共享 | 需要用户量支撑 |
| P3 | 社区基准 | 需要足够用户 + 隐私设计 |
| P3 | 游戏化 | 锦上添花 |
